- 봇이 많은 총격전에서 프레임이 크게 떨어지는 원인 중 하나: 총을 쏠 때 번쩍이는 불빛(점광원)이 그림자를 만들면, 게임이 주변을 그림자용으로 최대 6번 다시 그립니다. 총격전에서는 그림자 작업이 2배 넘게 늘어납니다.
- 켜면 봇·다른 플레이어의 총구 불빛은 그대로 주변을 밝히고 그림자만 만들지 않습니다. 내 총은 그대로입니다(쏠 때마다 총 주인을 확인 — 총은 재사용되므로).
- 끄면 다음 발사 때 원래 그림자 설정으로 돌아갑니다.
- 확인 상태: 빌드만 확인, 게임 미검증.

**2. 총구 연기 실내 처리를 프레임당 한 번만 (새 항목, '3. 그래픽 가볍게', 기본 꺼짐)**
- 게임이 세상의 총 한 자루마다 매 프레임 같은 '총구 연기가 실내인가' 계산을 반복합니다(모든 총이 같은 값을 씀). 총이 많을수록 일이 늘고, 실내·실외 전환이 총 개수만큼 빨리 진행되는 버그도 있었습니다.
- 켜면 프레임당 한 번만 계산합니다. 보이는 차이는 실내로 들어갈 때 연기 색 전환이 원래 의도대로 약 1초에 걸쳐 바뀌는 것뿐입니다.

**4. 불투명 물체를 재질별로 묶어 그리기 (새 항목, '4. 실험적', 기본 꺼짐)**

**<Changes (English)>**

**1. Others' muzzle flashes cast no shadows (new, section 3, off by default)**
- A muzzle flash that casts shadows makes the game redraw the area around it up to 6 times for the shadow map; in a big firefight that more than doubles the shadow work.
- With this on, bots' and other players' flashes still light things up, just without shadows. Your own gun is untouched (the owner is checked on every shot, since guns are pooled). Turning it off restores the original shadows on the next shot.
- Status: built only, untested in game.

**2. Muzzle smoke indoor update once per frame (new, section 3, off by default)**
- Every gun in the world redid the same shared "is the muzzle smoke indoors" update every frame, so the work grew with the number of guns and the indoor fade ran that many times too fast.
- With this on it runs once per frame. The only visible change: the smoke's indoor fade takes the intended ~1 s.
- Status: built only, untested in game.

**3. Presets**
- Light turns on item 2; Balanced and Max turn on items 1 and 2.

**4. Draw opaque objects grouped by material (new, section 4 experimental, off by default)**
- Fewer material switches for the CPU, a little more shading for the GPU; the picture is the same. Only helps on CPU-limited PCs — check with the benchmark key. Restored at raid end and while paused with the toggle key.
- Status: built only, untested in game.

**5. "DeClutter" tab on the RAM Cleaner (zzap) web page**
- With RAM Cleaner 2.15.0+ installed, `http://127.0.0.1:6977/` gets a tab with all of this mod's F12 settings (same behaviour as F12) and a status box refreshed every 3 s. The language follows RAM Cleaner.
- Status: tested without the game (Mono), untested in game.

**6. Other**
- `LICENSE` added: material from the original mod stays with its authors; new code for this port is MIT.
- Version and zip name 2.1.0.

**Known issues**
- All new items are untested in game; switch an item off to get the old behaviour back. Report `[DeClutter] patch '...' skipped` or `muzzle shadows failed` lines from `BepInEx\LogOutput.log`.

**Install / update**
- Extract `TYR_DeClutterer-2.1.0.zip` into your SPT folder and overwrite. Settings are kept (new items default to off).
