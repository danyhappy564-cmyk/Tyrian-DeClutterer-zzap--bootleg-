## TYR DeClutterer V 2.1.1 (SPT 4.1)

**- 멀리 있는 그림자 그리는 부담 줄이기 (실험적, 기본 꺼짐)**

■ 바뀐 것
- 먼 그림자 옛 지도 안 읽기(F12 "4. 실험적", 새 항목, 기본 꺼짐): 멀리 있는 건물·지형 그림자가 바뀔 때의 0.5초 섞기가 끝난 뒤에도 게임이 매 프레임 화면 전체에서 옛 그림자까지 읽던 것을, 섞기가 끝나면 새 것만 읽게 함. 화면은 같아야 함. 그래픽카드가 한계인 PC에서만 이득(1440p 약 0.4ms/프레임). (게임 미검증)
- RAM 클리너 웹 페이지(127.0.0.1:6977) "잡동사니·그래픽" 탭에서도 변경 가능
- 나머지는 2.1.0과 같음

■ 설치
- TYR_DeClutterer-2.1.1.zip 풀어서 SPT 폴더에 덮어쓰기 (설정 유지)

■ 주의
- 켰을 때 먼 그림자가 툭 바뀌거나 깜빡이면 끄면 원래대로 돌아갑니다.
