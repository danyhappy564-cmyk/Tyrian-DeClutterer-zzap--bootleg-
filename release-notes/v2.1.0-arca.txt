■ 바뀐 것

1) 다른 사람 총구 불빛의 그림자 끄기 (새 항목, 기본 꺼짐)
- 언제: 봇이 많은 총격전에서 프레임이 뚝 떨어질 때
- 왜: 총을 쏘면 번쩍이는 불빛이 그림자까지 만듭니다. 그때마다 게임이 주변을 그림자용으로 최대 6번 다시 그려서, 총격전에서는 그림자 작업이 2배 넘게 늘어납니다.
- 이제: F12 "3. 그래픽 가볍게"의 "다른 사람 총구 화염 그림자 끄기"를 켜면 봇이나 다른 사람 총구 불빛은 그대로 주변을 밝히고 그림자만 안 만듭니다. 내 총은 그대로입니다.
- 확인: 아직 게임에서 확인 못 했습니다.

2) 총구 연기 계산을 프레임당 한 번만 (새 항목, 기본 꺼짐)
- 왜: 게임이 총 한 자루마다 매 프레임 같은 계산을 반복합니다. 총이 많을수록 일이 늘고, 실내로 들어갈 때 연기 색이 바뀌는 속도도 총 개수만큼 빨라지는 버그가 있었습니다.
- 이제: "총구 연기 실내 처리 프레임당 1번"을 켜면 한 번만 계산합니다. 보이는 차이는 실내로 들어갈 때 연기 색이 원래 의도대로 1초 정도에 걸쳐 바뀌는 것뿐입니다.
- 확인: 아직 게임에서 확인 못 했습니다.

3) 프리셋에 반영
- 가벼움은 2번만, 균형과 최대는 1번과 2번 둘 다 켭니다.

4) 물체를 재질별로 묶어 그리기 (실험적, 기본 꺼짐)
- CPU 일을 조금 줄이는 대신 그래픽카드 일이 조금 늘어납니다. 화면은 똑같습니다.
- CPU 때문에 프레임이 안 나오는 PC에서만 이득이고, 그래픽카드가 먼저 한계인 PC에서는 오히려 느려질 수 있습니다. "효과 측정 키"로 켰을 때와 껐을 때를 비교해 보고 쓰세요.
- 확인: 아직 게임에서 확인 못 했습니다.

5) 웹 페이지에서 설정 바꾸기
- RAM 클리너(2.15.0 이상)가 같이 깔려 있으면, 브라우저 주소창에 127.0.0.1:6977 을 넣었을 때 나오는 RAM 클리너 웹 페이지 위쪽에 "잡동사니·그래픽" 탭이 생깁니다.
- F12와 같은 설정을 브라우저에서 바꿀 수 있고, 레이드 중이면 바로 다시 적용됩니다. 지금 레이드 중인지, 숨긴 물체가 몇 개인지 같은 상태도 3초마다 보입니다.
- 언어는 RAM 클리너 언어를 따라갑니다. 둘 중 하나만 깔아도 각자 정상 동작합니다.
- 확인: 게임 없이 설정 읽기와 바꾸기, 프리셋 적용까지 시험했고, 게임 안에서는 아직 확인 못 했습니다.

6) 기타
- 모드 버전과 업데이트 파일 이름이 2.1.0으로 바뀌었습니다.

새 항목은 전부 기본으로 꺼져 있어서 업데이트만 해서는 달라지는 게 없습니다. 켜 보고 이상하면 그 항목만 다시 끄면 원래대로 돌아갑니다.
