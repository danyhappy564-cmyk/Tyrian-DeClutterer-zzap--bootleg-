**<변경점>**

**1. SPT 4.1 지원 (새로 짬)**
- 원본 1.1.5는 SPT 3.x용(옛 `Aki` 라이브러리, 3.x 게임 내부 이름)이라 4.1에서는 로드조차 안 됩니다.
- 같은 기능을 4.1 게임 구조에 맞춰 다시 짰습니다. 4.1에서 없어진 대상(구름 컨트롤러, 주변광 내부 메서드)을 고치던 기능은 빼거나 안전한 방식으로 바꿨습니다.
- 모드 ID(`com.TYR.DeClutter`)는 원본과 같게 둬서 원본 dll과 같이 깔려도 하나만 로드됩니다. 설정 항목 이름이 바뀌어 설정은 기본값부터 시작합니다.

**2. 원본에서 고친 문제**
- 레이드 시작 순간 맵 전체 물체를 한 프레임에 검사해서 멈칫 → 여러 프레임에 나눠 검사(프레임당 2ms 목표). 세관 첫 검사 5.7초 동안 나눠서 처리.
- 분류(쓰레기·음식 등)를 레이드 중에 켜고 꺼도 반영 안 됨 → 바로 반영(숨긴 것 되살리기 포함).
- "Fire & Smoke Changes"가 설명(맵 불·연기 제거)과 달리 **불 데미지 자체를 끔**(사실상 치트) → 불 데미지 끄기는 삭제. 불·연기 그림만 숨기고, 데미지 구역이 있는 불은 유지.
- 그래픽 원래 값을 게임을 켤 때 저장해서, 나중에 게임 그래픽 설정을 바꾸면 끌 때 옛 값으로 되돌아감 → 레이드 시작 때 저장, 레이드 끝에 복원.
- 조명 개수 값이 그림자 값이 1보다 클 때만 적용 → 각각 따로 적용. 그림자 단계 토글을 바꿔도 즉시 반영 안 되던 것도 수정.
- 충돌체 판정이 일부 종류만 봐서 총알이 맞는 물체까지 숨길 수 있었음(엄폐·탄도가 바뀜) → 충돌체가 하나라도 있으면 숨기지 않음.
- 퀘스트 구역·문·스위치·탈출구·루팅 보호가 부족 → 보호 대상에 추가.
- "물리 절반"이 실제로는 물리를 슬로모션으로 만듦 → 건너뛴 시간을 다음 계산에 더하도록 고침(실험적 항목).
- 하이드아웃 판정이 씬 이름 고정 → 게임 월드 종류로 판정. 설정을 바꿀 때마다 패치를 새로 걸던 구조 → 시작 때 한 번만.

**3. 새 기능**
- F12 설정 **한/영** 전환, **프리셋**(모두 끔 / 가벼움 / 균형 / 최대). 고른 프리셋 이름이 남고, 항목을 직접 바꾸면 '직접 설정'으로 바뀝니다.
- **멀리서만 숨김**: 가까이선 그대로 보이고 정한 거리(기본 25m)보다 멀면 사라짐.
- **튀는 탄피 최대 개수**, **총알 자국 최대 개수·보이는 거리** (줄이는 쪽으로만).
- **레이드 중 켜기/끄기 키**, **효과 측정 키**(켬 5초 / 끔 5초 평균 FPS), **물체 이름 확인 키**(화면 가운데 물체가 숨겨졌는지와 이유).
- **exclude.txt**: 숨기면 안 되는 물체 이름을 적으면 다음 레이드부터 제외(맵별 지정 가능).
- 레이드 시작 때 로그 한 줄 요약(후보 수, 분류별 숨김 수, 검사 시간).
- **4. 실험적(기본 꺼짐)**: 물리 계산 절반, 하늘·날씨 계산 격프레임, 주변 반사 갱신 간격, 풀 보이는 거리(배율 스코프로 조준 중엔 원래 거리), 이름 상관없이 작은 장식 전부 숨김.

**4. 맵 데칼(낙서·얼룩·핏자국)은 맵을 불러올 때 뺌**
- 레이드 중에 데칼 수천 개를 끄면 게임이 끌 때마다 데칼 그리기 목록 전체를 다시 만들어, 개발 중 측정에서 20초 넘게 분당 수백 MB의 임시 메모리가 쌓였습니다(레이드 중엔 게임이 메모리 정리를 꺼 둠).
- 그래서 데칼은 맵 로드 때 그리기 목록에 넣지 않는 방식입니다. 레이드 중 비용이 없는 대신, 데칼 설정은 **다음 레이드부터** 적용되고 켜기/끄기 키·측정에도 영향받지 않습니다.

**5. 다른 모드와 같이 쓰기 (코드 대조)**
- SAIN·ORBIT: 충돌체 있는 물체, 문·퀘스트 구역·루팅·탈출구·지뢰 구역·스폰 지점은 숨기지 않아 봇 판단에 영향 없음.
- HollywoodFX: 이펙트 풀은 숨기지 않음. 총알 자국 한도는 이 모드 값이 0이면 HFX 값 그대로. 탄피 제한은 HFX의 60초 탄피와 같이 쓰면 오히려 도움.
- HollywoodGraphics: 풀 거리 설정이 0이면 손대지 않음.
- 배율 스코프 / PiP-Disabler: 스코프만 따로 건드리는 기능 없음.

**측정 (제작자 PC: RTX 4080, 모드 140개, 세관, FPS 상한 해제)**
- "완전히 숨김"(균형 프리셋): 효과 측정 7번 중앙값 **+10%** (범위 -2 ~ +24%, 약 110~135fps 구간). 맵 데칼은 켬·끔 양쪽 다 숨긴 채로 잰 값이라 실제 이득은 조금 더 큼.
- "멀리서만 숨김": +3% (1번).
- FPS 상한(프레임 제한·수직동기·프레임 생성 상한)이 걸려 있으면 숫자 차이는 안 보이고 그래픽카드 부담만 줄어듭니다. PC에 따라 차이가 큽니다.
- 측정 키 끊김·레이드 중 메모리 증가 문제는 제작자 테스트에서 해결 확인.

**알려진 점**
- 레이드 시작 직후 한 번, 큰 맵 묶음을 검사하는 프레임이 40ms 정도 걸릴 수 있습니다.
- 실험적 4종(물리 절반·하늘 격프레임·반사 간격·풀 거리)은 게임에서 충분히 확인하지 못했습니다. HollywoodFX 래그돌과 '물리 계산 절반'은 같이 쓰지 마세요.
- 퀘스트 물체를 전부 확인하지는 못했습니다. 사라지면 안 되는 물체가 보이면 "물체 이름 확인 키" 결과와 LogOutput.log를 주세요. 급하면 exclude.txt에 이름을 넣으면 됩니다.
- 숨긴 물체는 메모리(RAM·VRAM)를 줄이지 않습니다(FPS용 모드).

**설치 / 업데이트**
- `TYR_DeClutterer-2.0.0.zip` 압축을 풀어 SPT 폴더에 덮어쓰기 → `BepInEx/plugins/TYR_DeClutterer/` 안에 dll과 exclude.txt.
- 예전 원본 `TYR_DeClutterer.dll`(3.x용)이 `BepInEx/plugins`에 있으면 지우세요.
- 추천 시작값: F12 → 1. 일반 → 프리셋 "균형".

**<Changes (English)>**

**1. SPT 4.1 support (rewritten)**
- The original 1.1.5 targets SPT 3.x and does not load on 4.1. Rewritten for 4.1; features whose 3.x targets no longer exist (cloud controller, ambient-light internals) were dropped or replaced with safer equivalents.
- Same plugin ID (`com.TYR.DeClutter`) so only one copy loads. Setting names changed, so settings start from defaults.

**2. Fixed from the original**
- Whole-map scan in a single frame at raid start (hitch) → spread over frames (~2 ms per frame).
- Category toggles ignored during a raid → applied immediately (restoring hidden objects too).
- "Fire & Smoke Changes" actually disabled fire damage (a cheat) → removed; only fire/smoke visuals are hidden, fires with damage zones are kept.
- Graphics defaults captured at game start, restoring stale values later → captured at raid start, restored at raid end.
- Pixel light divider only applied when the shadow divider was above 1; shadow cascade toggle not applied live → both fixed.
- Collider check missed some collider types and could hide bullet-blocking objects → any collider keeps the object.
- Quest zones, doors, switches, exfils and loot better protected.
- "Physics half rate" made physics run in slow motion → skipped time is carried over (experimental).
- Hideout detection by scene name → by world type. Patches applied once instead of on every setting change.

**3. New**
- Korean/English F12 page; presets (All off / Light / Balanced / Max). The chosen preset name stays until you change an item.
- Hide-at-distance mode (default 25 m); shell cap; bullet decal cap and draw distance (only ever lowered).
- In-raid toggle key, benchmark key (5 s on / 5 s off average FPS), inspect key (why the object at screen centre is hidden or kept).
- exclude.txt (per-map entries supported); one-line scan summary in the log.
- Experimental (off by default): physics half rate, sky/weather every other frame, ambient reflection interval, grass distance (original distance while aiming through a magnified scope), hide everything small.

**4. Map decals are excluded while the map loads**
- Disabling thousands of decals mid-raid made the game rebuild its decal draw list every time, producing hundreds of MB of garbage per minute for 20+ seconds in testing. Decals are now kept out of the draw list at load: zero in-raid cost, but decal changes apply from the next raid and the toggle/benchmark keys do not affect them.

**5. Compatibility (checked against source)**
- SAIN/ORBIT: colliders, doors, quest zones, loot, exfils, minefields and spawn points are never hidden.
- HollywoodFX: effect pools untouched; decal limit untouched at 0; the shell cap helps with HFX's 60 s shells. HollywoodGraphics: grass untouched at 0. Scopes / PiP-Disabler: nothing scope-specific is changed.

**Measured (author's PC: RTX 4080, 140 mods, Customs, no FPS cap)**
- Hide completely (Balanced): median **+10%** over 7 runs (range -2 to +24%, ~110-135 fps). Map decals were hidden in both runs, so the real gain is a bit higher. Hide at distance: +3% (1 run).
- With an FPS cap the number does not change; only GPU load drops. Results vary a lot by PC.

**Known issues**
- One ~40 ms frame may occur right after raid start while a large map section is scanned.
- The four experimental options are not fully tested in game. Do not combine HollywoodFX ragdolls with Physics half rate.
- Not every quest object was checked; if something that matters disappears, send the inspect-key result and LogOutput.log, or add its name to exclude.txt.
- Hidden objects do not reduce RAM/VRAM (this is an FPS mod).

**Install / update**
- Extract `TYR_DeClutterer-2.0.0.zip` into your SPT folder → `BepInEx/plugins/TYR_DeClutterer/`. Remove the old 3.x `TYR_DeClutterer.dll` if present. Suggested start: preset "Balanced".

If people ignore warning 2. and act as if my port is the "real deal," I would feel immense guilt.
