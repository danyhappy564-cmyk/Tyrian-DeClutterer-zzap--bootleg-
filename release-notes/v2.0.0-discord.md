## TYR DeClutterer V 2.0.0 (SPT 4.1)

**- 바닥 잡동사니를 숨겨 FPS 올리기 · 4.1 포팅 + 원본 문제 수정**

■ 바뀐 것
- SPT 4.1용으로 새로 짬 (원본은 3.x용이라 4.1에서 안 켜짐)
- 레이드 시작 순간 멈칫하던 검사를 여러 장면에 나눔
- 원본 "불·연기 제거"가 실제로는 불 데미지를 끄던 문제 삭제 (그림만 숨김)
- 레이드 중 분류 켜기/끄기 바로 반영, 총알 맞는 물체·퀘스트·문·탈출구는 절대 안 숨김 (SAIN·ORBIT 영향 없음)
- 맵 낙서·얼룩은 맵을 불러올 때 빼서 레이드 중 부담 없음 (바꾸면 다음 레이드부터)
- 새 기능: 한/영 설정, 프리셋, 멀리서만 숨김, 탄피·총알 자국 개수 제한, 켜기/끄기 키, 효과 측정 키, 물체 이름 확인 키
- 제작자 PC(RTX 4080, FPS 제한 해제) "균형" 기준 약 +10% (PC마다 차이 큼)

■ 설치
- zip 풀어서 SPT 폴더에 덮어쓰기, 예전 3.x용 모드 파일은 삭제
- 설정은 기본값부터 시작, 처음엔 프리셋 "균형" 추천

■ 주의
- FPS 제한을 걸어 두면 숫자 변화는 안 보임 (그래픽카드 부담만 줄어듦)
- "4. 실험적" 항목은 기본 꺼짐, 충분히 확인 못 함 (물리 절반은 Hollywood FX 시체 연출과 같이 쓰지 말 것)
- 비공식 포팅판입니다. 원작자분께 문의하지 말아 주세요
