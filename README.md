## 이 모드가 하는 일

맵 바닥에 깔린 **작은 장식 물체**(쓰레기, 종이, 빈 캔, 포스터, 잔해, 낙서 데칼, 가짜 웅덩이 등)를 숨기고, 원하면 **그래픽 설정 몇 가지를 낮춰서** FPS를 올립니다.

- **숨기지 않는 것**: 충돌체가 있는 물체(총알이 맞거나 발에 걸리는 것, 밟으면 소리 나는 유리 파편 포함), 루팅 아이템·상자, 문·스위치·탈출구·퀘스트 구역, 소리·조명이 붙은 물체, 봇·플레이어.
  → 숨기는 건 "보이기만 하는" 물체라 **총알·엄폐·발소리·봇(SAIN 포함) 판단은 그대로**입니다.
- **숨긴 물체는 메모리를 줄이지 않습니다**(그리기만 안 함). 메모리 정리용 모드가 아니라 FPS용 모드입니다.
- 하이드아웃에서는 아무것도 하지 않습니다.
- 레이드가 끝나면 바꾼 그래픽 값은 모두 원래대로 돌아갑니다.

## 설치

1. `TYR_DeClutterer-2.0.0.zip`을 SPT 폴더(`E:\SPT 4.1`)에 풀면 `BepInEx\plugins\TYR_DeClutterer\` 아래에 `TYR_DeClutterer.dll`과 `exclude.txt`가 생깁니다.
2. 예전 원본 `TYR_DeClutterer.dll`(SPT 3.x용)이 `BepInEx\plugins`에 있으면 지우세요. (같은 ID라 둘 중 하나만 로드되지만 헷갈리지 않게)
3. 설정은 게임 안에서 **F12**. 설정 파일은 `BepInEx\config\com.TYR.DeClutter.cfg`입니다. 원본과 항목 이름이 달라서 처음엔 기본값으로 시작합니다.

### 4. 실험적 (기본 꺼짐)

|---|---|
| 물리 계산 절반 | 시체·던진 수류탄·떨어진 물건을 두 프레임에 한 번 계산. 원본은 물리가 **슬로모션**이 되던 문제가 있어서, 건너뛴 시간을 모아 다음 계산에 더하도록 고침. 수류탄 궤적·시체 움직임이 살짝 거칠어질 수 있음 |

| 풀 보이는 거리 | 일반 화면의 풀 거리. **배율 스코프로 조준하는 동안엔 원래 거리**로 돌아감. 봇은 풀 그리기와 무관하므로 줄이면 플레이어만 멀리 적을 보기 쉬워짐(공정성 주의) |
| 이름 상관없이 작은 장식 전부 숨김 | 원본의 'Unscrutinized'. FPS는 크게 오르지만 맵이 휑해지고 엉뚱한 물체가 사라질 수 있음 |
| 불투명 물체를 재질별로 묶어 그리기 | 화면은 같고, 재질 전환이 줄어 CPU 일이 줄어든 만큼 그래픽카드 일이 조금 늘어남. 그래픽카드가 한계인 PC에선 오히려 느려질 수 있으니 효과 측정 키로 확인 |

## 숨기면 안 되는 물체가 사라졌을 때 (exclude.txt)

1. F12 → 1. 일반 → **물체 이름 확인 키**를 정합니다.
2. 레이드에서 그 물체가 있던 자리를 화면 가운데에 두고 키를 누르면 `BepInEx\LogOutput.log`에 `[DeClutter] Inspect: '물체이름' ...`이 남습니다.
3. `BepInEx\plugins\TYR_DeClutterer\exclude.txt`에 그 이름(일부만 써도 됨)을 한 줄 적습니다. 특정 맵에서만 빼려면 `맵ID:이름`(예: `woods:sticks`).
4. **다음 레이드부터** 적용됩니다(게임 재시작 불필요).

## 로그로 확인하기

레이드 시작 몇 초 뒤 `LogOutput.log`에 이런 줄이 한 번 남습니다.

```
[DeClutter] 레이드 시작 검사 (bigmap): 후보 23412개 → 숨김 1234개(쓰레기 600, 더미 300, ...), 멀리서만 0개 / 안 숨김: 충돌체 3400, 보호 120, ... / 230프레임, 프레임당 최대 2.1ms, 총 4.0초
```

- **후보가 0개**면 맵이 덜 실린 시점에 검사한 것일 수 있습니다 — 로그와 함께 알려 주세요.
- "패치 skipped" 경고가 있으면 그 기능(탄피 제한·물리·날씨)이 이 게임 버전과 안 맞아서 꺼진 것입니다. 나머지 기능은 그대로 돕니다.

## 다른 모드와 같이 쓸 때

코드를 직접 대조해서 확인한 내용입니다(인게임 확인 전).

**HollywoodFX**
- 총알 자국: HFX는 한도를 2048로 늘립니다. 이 모드의 '총알 자국 최대 개수'가 0(기본)이면 **손대지 않아** HFX 값이 그대로입니다. 숫자를 넣으면 그 값까지 **줄이기만** 합니다(HFX의 탄흔 그리기와 같은 장치를 써서 충돌 없음).
- 탄피: HFX는 탄피를 60초 남기고 1.5배 키웁니다. 이 모드의 '튀는 탄피 최대 개수'를 쓰면 오래된 탄피부터 지웁니다. 크기는 탄피가 풀로 돌아갈 때 게임이 원래대로 되돌리므로 커지는 일이 쌓이지 않습니다.
- 이펙트: HFX가 미리 만들어 둔 연기·먼지·폭발 효과와 게임 기본 이펙트는 **숨기지 않습니다**(멈춰 있는 이펙트, 이펙트 장치 아래에 있는 것, 오브젝트 풀은 제외).
- 래그돌: '4. 실험적 → 물리 계산 절반'은 HFX의 시체 연출과 같이 쓰면 시체가 튈 수 있어 **권장하지 않습니다**.
- 그래픽 값: HFX는 그래픽 품질 값(그림자·LOD 등)을 바꾸지 않으므로 겹치지 않습니다.

**HollywoodGraphics**
- 풀 거리: HG는 맵 로드 때 풀 거리를 배율로 바꿉니다. 이 모드의 '풀 보이는 거리'가 0(기본)이면 **손대지 않습니다**. 숫자를 넣으면 HG가 바꾼 값과 그 숫자 중 **작은 쪽**을 쓰고, 레이드가 끝나면 HG가 바꾼 값으로 되돌립니다.
- 조명: HG가 손보는 램프(빛 번짐)는 조명이 붙어 있어 숨기지 않습니다. HG의 블룸·AO·모션 블러와는 겹치는 부분이 없습니다.

**ORBIT**
- ORBIT는 레이드 시작 때 문·퀘스트 구역·루팅·탈출구·지뢰 구역·스폰 지점을 찾습니다. 이것들과 그 상위 물체는 **모두 숨기지 않습니다**.
- ORBIT의 엄폐 판정·레이캐스트는 충돌체 기준인데, 이 모드는 충돌체 있는 물체를 숨기지 않으므로 영향이 없습니다. ORBIT가 봇을 잠시 꺼 두는 기능(Dormancy)과도 겹치지 않습니다.

**SAIN**: 충돌체가 있는 물체는 절대 안 숨기므로 봇의 시야·엄폐·소리 판단에 영향이 없습니다(실험적 '물리 절반'은 수류탄 궤적이 살짝 달라질 수 있음).

**배율 스코프 / PiP-Disabler**: 스코프 화면만 따로 건드리는 기능은 없습니다. 그래픽 값은 게임 그래픽 설정처럼 일반 화면과 스코프에 똑같이 적용되고, 풀 거리는 조준 중 원래대로 돌아갑니다. '멀리서만 숨김'은 시야각 기준이라 스코프로 보면 더 멀리까지 보입니다(게임의 LOD와 같은 원리).

**RamCleaner 같은 메모리 정리 모드**: 겹치는 기능이 없습니다. 레이드 시작 검사를 여러 프레임에 나눠서 하므로 같은 시점에 부담이 몰리지 않습니다.

**RAM 클리너(zzap) 웹 페이지**: RAM 클리너가 같이 깔려 있으면 `http://127.0.0.1:6977/` 위쪽 메뉴에 **'잡동사니·그래픽'** 탭이 생깁니다(SPT 런처의 RAM Cleaner 모드 페이지에서도 같음). 이 모드의 F12 설정 전체를 브라우저에서 바꿀 수 있고, F12에서 바꾼 것과 똑같이 동작합니다(프리셋, 레이드 중 다시 적용, 설정 파일 저장). 현재 상태(레이드 중인지, 숨긴 물체 수, 로드 때 뺀 데칼 수, 프리셋)도 3초마다 보여 줍니다. RAM 클리너 언어를 바꾸면 이 모드 언어도 따라 바뀝니다. 서로 없어도 각자 정상 동작합니다.

**Smoothie**: 같은 아이디어(총구 화염 그림자·재질별 정렬)가 Smoothie에도 있습니다. 둘 다 켜도 같은 값을 쓰는 것이라 충돌은 없지만 한쪽만 켜는 걸 권장합니다.

## 확인 상태

- **측정(2026-10-15, 세관, RTX 4080·FPS 상한 해제)**: 완전히 숨김 중앙값 **+10%**(7회, -2~+24%), 멀리서만 숨김 +3%(1회). 맵 데칼은 양쪽 다 숨긴 채로 잰 값이라 실제 이득은 이보다 조금 더 큼. FPS 상한이 걸려 있으면 숫자 차이는 안 보이고 그래픽카드 부담만 줄어듭니다.

- 빌드: 4.1 게임 어셈블리 기준 오류 0·경고 0 (컨테이너, 2.1.0 포함).
- 2.1.0 새 항목: 대상 게임 메서드·필드 이름과 매개변수를 4.1 게임 코드(디컴파일)와 대조함. 웹 탭은 게임 없이(Mono) RAM 클리너 웹 코드로 이 모드 설정을 읽기·쓰기·프리셋 적용·범위 보정까지 시험함. **인게임은 확인 전** — 문제 있으면 로그에 `patch '...' skipped`나 `muzzle shadows failed`가 남습니다.
- **인게임: 아직 확인 전.** 특히 확인이 필요한 것 — 레이드 시작 때 멈칫이 없는지, 검사 로그 숫자, 퀘스트 물체·문이 멀쩡한지, '멀리서만 숨김' 거리감, 탄피·총알 자국 제한, 실험적 항목 4개.
